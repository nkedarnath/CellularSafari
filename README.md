# CellularSafari: Mapping the Human Brain 

Welcome to Cellular Safari, an introductory course designed for junior-track students to explore the wonders of the human brain through data! /
This repository contains all the webpage files, course materials, and hands-on activities for the program./

## About the Course
Cellular Safari takes students on a guided journey from basic brain anatomy to the cutting edge genomic science. The Junior track participants will learn how single cells work together to create the human mind and discover how scientists map these cells using modern computational tools.

## Key Learning Topics
1. Brain Architecture: Understanding major brain regions and their functions.
2. Cellular Biology: Discovering neurons, glia, and how they communicate.
3. Single-Cell Transcriptomics: An introduction to reading the genetic code of individual cells.
4. Spatial Transcriptomics: Learning how scientists map genetic activity directly onto brain tissue images.
5. Data analysis: How multidimensional data is analysed to reveal patterns in brain tissues and help discover new biology
